# Roadmap

## Completed

- Fullstack React + Express + MongoDB project setup
- JWT-based authentication with register, login, and current-user profile flow
- Product seed script for local MongoDB development
- Homepage with promotions, new arrivals, best sellers, and ranking sections
- Product listing page with search, filters, sorting, and pagination
- Product detail page with gallery, pricing, size/color selection, and related products
- Category browsing page with infinite scroll sections
- Responsive storefront UI using Tailwind CSS, Swiper, and Ant Design icons
- Frontend structure refactor into `api`, `components/common`, `components/layout`, `components/products`, and `routes`
- Portfolio-ready project documentation and environment examples

## In Progress

- Portfolio hardening and cleanup of developer experience
- Better automated verification workflow for frontend and backend startup
- Documentation refinement for internship presentation and review
